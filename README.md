# GAMUDEV - Portafolio Personal

Portafolio web personal de Javier Garcia Muñoz, desarrollador FullStack con experiencia en Java, JavaScript, Spring y más tecnologías.

## 🚀 Características

- **Portafolio interactivo** con proyectos demostrativos
- **Juegos y aplicaciones web** desarrollados con HTML, CSS y JavaScript
- **Diseño responsive** optimizado para todos los dispositivos
- **Tema oscuro/claro** con persistencia de preferencias
- **Accesibilidad mejorada** con soporte ARIA y navegación por teclado

## 📁 Estructura del Proyecto

```
gamudev.github.io/
├── Demo/                    # Proyectos demostrativos
│   ├── Buscaminas/         # Juego de buscaminas
│   ├── Calculadora/         # Calculadora funcional
│   ├── Encuentra Pareja Fruta/  # Juego de memoria
│   ├── Obstacles/           # Juego de obstáculos
│   ├── Race/                # Juego de carreras
│   ├── Snake/               # Juego de la serpiente
│   ├── Tetris/              # Juego de Tetris
│   └── Tres En Raya/        # Juego de tres en raya

```

## 🎮 Proyectos Incluidos

### 1. Calculadora
Calculadora funcional con soporte para operaciones básicas, porcentajes y potencias. Incluye validación de errores y soporte para teclado.

### 2. Tetris
Implementación clásica del juego Tetris con controles de teclado.

### 3. Snake
Juego de la serpiente con soporte para dispositivos móviles y de escritorio.

### 4. Buscaminas
Juego de buscaminas con lógica de descubrimiento automático de casillas.

### 5. Tres en Raya
Juego de tres en raya para dos jugadores.

### 6. Juego de Memoria
Juego de encontrar parejas con temática de frutas.

## 🚀 Instalación y Uso

1. Clona el repositorio:
```bash
git clone https://github.com/gamudev/gamudev.github.io.git
```

2. Abre `index.html` en tu navegador web.

O si prefieres usar un servidor local:

```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (http-server)
npx http-server

# Con PHP
php -S localhost:8000
```

3. Navega a `http://localhost:8000` en tu navegador.
